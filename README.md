# ToDoListApp

Ung dung quan ly cong viec don gian, giup nguoi dung them, theo doi va quan ly danh sach viec can lam hang ngay.

## Tinh nang

- Them cong viec moi
- Hien thi danh sach cong viec
- Cap nhat trang thai cong viec
- Xoa cong viec khoi danh sach
- Giao dien don gian, de su dung

## Cong nghe su dung

- HTML
- CSS
- JavaScript

## Cach chay du an

1. Clone repository:

```bash
git clone https://github.com/PKhanh-1601/ToDoListApp.git
```

2. Mo thu muc du an:

```bash
cd ToDoListApp
```

3. Mo file `index.html` bang trinh duyet.
